# Null Pointers — openJiuwen Challenge 2026

Основная модель — `qwen3.8-27b-noreason`. Для математических задач, требующих вызова модели, при достаточном остатке бюджета используется `qwen3.8-27b` с рассуждением. Обе модели вызываются через openJiuwen 0.1.19.

## Запуск

Выполните из корня репозитория на Linux x86-64 в окружении с сетью `hack-net`.

```bash
docker build -t hack:latest .
docker run --rm --network hack-net \
  -e LLM_BASE_URL -e LLM_API_KEY -e BUDGET \
  -v "$TASKS:/data/tasks:rw" \
  --read-only --tmpfs /tmp:rw,size=2g -e HOME=/tmp \
  --cap-drop ALL --security-opt no-new-privileges \
  --cpus 4 --memory 16g --pids-limit 512 \
  hack:latest --tasks-dir /data/tasks
```

`TASKS` — абсолютный путь к каталогу с задачами на хосте. Адрес и ключ прокси передаются в `LLM_BASE_URL` и `LLM_API_KEY`. `BUDGET` задаёт лимит в единицах выходного токена и по умолчанию равен 100 000. Зависимости устанавливаются при сборке. При запуске агент обращается только к прокси.

## Решение и бюджет

- Агент сначала пробует решить задачи локально. Для остальных он оценивает расход по типу задачи и объёму входа, затем сортирует их по убыванию `reward / оценка расхода`. Вызовы модели учитываются по данным `usage` как `выходные + входные / 10`. В выходные входят токены рассуждения. Перед параллельными вызовами агент резервирует часть бюджета.
- Для расчётов по CSV агент может попросить модель описать операцию и фильтры. Код проверяет этот план и считает по полным таблицам, включая доли по группам и уникальным участникам, а также сравнения с медианой или средним.
- Агент пропускает задачу при обнаружении недостающих данных или противоречий. Например, он проверяет наличие нужных столбцов CSV, знаменатель доли и противоречащие друг другу утверждения в тестах Python. Для поиска по длинным текстам он проверяет цитату из источника. Сложные математические условия дополнительно проверяет модель.
- Готовый ответ сохраняется в `answer.txt` рядом с `task.json`. При пропуске файл не создаётся. Для задач Python агент сохраняет правку и записывает `DONE` после прохождения исходных тестов.

## Тренировочные прогоны

Для проверки использовались собственные синтетические задачи. Агент пишет траекторию прогона в stdout в формате JSONL. Журнал содержит результат каждой задачи, выбранную модель, расход и остаток бюджета. Чтобы собрать небольшой набор на хосте, запустите `python training.py generate practice-17 --seed 17`, укажите его абсолютный путь в `TASKS` и выполните команду Docker выше. Для сохранения журнала добавьте `> practice-17.jsonl`. Оцените результат командой `python training.py score practice-17`.
